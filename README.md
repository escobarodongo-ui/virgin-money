# Go Account

Unofficial demo recreation of a mobile banking account screen, laid out for a phone. It is not operated by Virgin Money, does not connect to Virgin Money, and cannot move money or sign in to a real account. Balances and transactions are fictional.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL. The account screen is the Accounts tab.

## Build

```bash
npm run build
npm run preview
```

## Checks

```bash
npm test
```
